### What it does

Obsidian plugin that displays daily and weekly reflections generated by a companion Node engine. It records section-level changes to your notes and surfaces things you would not notice yourself — repeated restarts, churn without closure, conclusions that flipped. The insight layer can return nothing, and does so deliberately rather than padding output.

### Notes

The plugin is a thin viewer/launcher. Reflection generation happens in an external Node process so it can run while Obsidian is closed; the plugin only reads the generated Markdown and can trigger a regeneration on demand.

The UI strings are currently Chinese; English localization is on the roadmap. The "About" page inside the panel is in English.
